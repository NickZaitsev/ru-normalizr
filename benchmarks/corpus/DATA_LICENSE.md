# Данные для benchmark ru-normalizr

Исходные произведения скачаны из Русской Викитеки.

Статусы public domain указаны по страницам Викитеки: `PD-old-70` или `PD-RusEmpire`.

В репозитории для каждого корпуса сохранены:

- `.txt` — производный plain-text после удаления MediaWiki-разметки;
- `MANIFEST.json` — источник, статус, количество страниц и SHA-256 plain-text-файла.

Исходные `.wikitext.jsonl`/`.rendered.jsonl` и промежуточные `.metadata.json`
использовались при подготовке корпуса, но в benchmark-репозиторий не входят.

Код нормализатора и текстовые данные следует лицензировать и распространять отдельно.

Источник и правила авторских прав:
https://ru.wikisource.org/wiki/Викитека:Авторские_права

Источники корпусов указаны в `MANIFEST.json`.
