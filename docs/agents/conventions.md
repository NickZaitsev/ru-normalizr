# Output conventions

- A parameter noun before a measurement (`при температуре 660 °C`, `со
  скоростью 60 км/ч`, `диаметром 5 м`) is named by that measurement, so the
  measurement is an apposition and stays nominative in any case the parameter
  itself carries. The genitive reading needs an explicit `в` in the source:
  `при температуре в 660 градусов`. The closed list of these nouns lives in
  `MEASURE_PARAMETER_HEADS`.
- A relational quantity noun in the `в …` frame governs a genitive instead,
  because the quantity is its complement, not an apposition: `в возрасте
  двадцати пяти лет`, `в количестве пяти штук`, `в размере пятисот рублей`
  (`LOCATIVE_GENITIVE_QUANTITY_HEADS`).
- A counted unit inside a measurement apposition is never oblique. `двухстах
  метрах`, `двух атмосферах` and `пяти километрах в час` are ungrammatical *in
  that reading*, so no case from the parameter noun may reach the unit;
  `tests/test_morphology_policy.py` asserts this as an invariant. The ban is
  about the apposition, not about units in general: distance from a landmark
  puts both the numeral and the unit in the locative (`в двухстах метрах от
  реки`), and the next bullet spells that out.
- Government from outside the quantity is unaffected: `в 200 м от реки` →
  `в двухстах метрах от реки`, `в 12 городах` → `в двенадцати городах`.
- Ranges with `с … по …` end in singular `год` / `век`; `до … века` is also
  singular.
- Byte-family units use ordinary Russian counting forms consistently:
  `1 байт`, `2–4 байта`, `5 байтов`, including prefixed units.
- Регистр латинских информационных обозначений является частью смысла:
  `Mb`, `Mbps`, `Mb/s` — мегабиты, а `MB`, `MBps`, `MB/s` — мегабайты.
  Неизвестный неоднозначный вариант регистра не угадывается.
- Ограниченные составные единицы читаются целиком: `/` задаёт сохранённое в
  реестре отношение (`мг/кг` → «миллиграммов на килограмм», `мл/мин` →
  «миллилитров в минуту»), а `·` — лексикализованное произведение
  (`кВт·ч` → «киловатт-час»). Вложенные и неизвестные выражения не разбираются.
- Метка идентификатора не измерение и падежа от фразы не получает: она
  читается в именительном. Учётный номер при метке (`ИНН`, `ОГРН`, `ОГРНИП`,
  `КПП`, `БИК`, `ОКПО`) читается по цифрам с сохранением начальных нулей:
  `ИНН 7701234567` → «ИНН семь семь ноль один два три четыре пять шесть семь».
  Обозначение стандарта при метке (`ГОСТ`, `ISO`, `IEC`) читается группами:
  точка произносится словом, дефис даёт пробел, двоеточие — паузу запятой
  (`ГОСТ 2.105-95` → «гост два точка сто пять девяносто пять»,
  `ISO 9001:2015` → «ай эс о девять тысяч один, две тысячи пятнадцать»).
  Список меток и допустимых форм кода закрыт: неизвестная метка перед числом
  идентификатором не объявляется, а метка с кодом неожидаемой формы
  (`ИНН 7701`, `ISO 8601`) остаётся обычному разбору.
- Буква внутри компактного буквенно-цифрового кода читается именем буквы, а не
  единицей измерения: `24H2` → «двадцать четыре эйч два». Настоящая единица
  стоит после числа, а не между двумя числами.
- References governed by `см.` / `смотри` use an accusative reference noun and
  a cardinal label: `смотри рисунок два, таблицу три, страницу четыре`. The
  directive governs the whole enumeration, not just the first item.
- Сокращённое ссылочное существительное с номером (`ст. 5`, `п. 2`, `табл. 3`,
  `прил. 2`, `рис. 2`, `стр. 4`, `с. 6`) получает падеж от управления слева, а
  номер остаётся меткой в именительном: `согласно статье пять пункту два`,
  `в таблице три`. Второй маркер цепочки повторяет падеж первого. Заглавная у
  маркера сохраняется как начало предложения, кроме библиографических
  `С.`/`P.`/`Стр.`, где она — традиция записи, а не граница.
- Сокращение существительного без номера склоняется по левому контексту
  (`в Московской области`, `в таблице`, `в рублях`); предлог ищется через
  согласованные определения. Счётная форма валюты (`рублей`, `долларов`)
  требует количества слева.
- `г.` перед именем населённого пункта читается «город» в падеже контекста
  (`в г. Казань` → «в городе Казань», при глаголе движения — «в город Казань»).
  Имя должно быть словарным географическим и стоять в форме, которая
  укладывается в конструкцию; рядом с формой рельефа (`у подножия г. Эльбрус`)
  и перед фамилией (`г. Иванов`) сокращение остаётся как было.
- `Св.` читается прилагательным «святой», согласованным с тем, что стоит
  справа, по разбору: «святая Ольга», «Святой Анны», «Святого Николая»,
  «Святое Писание», «Святых Тайн».
- `гл.` перед одушевлённой должностью или падежом, которым «глава» не
  управляет, читается прилагательным «главный» и согласуется с ней
  (`гл. редактор` → «Главный редактор», `гл. образом` → «главным образом»).
  Родительный неодушевлённого целого справа (`гл. книги`, `гл. города`) —
  управление существительного «глава», а номер рубрики читается порядковым:
  `гл. 5` → «глава пятая», `в 8 гл.` → «в восьмой главе».
- Default and safe initial settings use ordinary Russian letter names (`Е. → е`)
  and preserve source punctuation, including when initial expansion is enabled.
- TTS initial settings double isolated vowel names (`Е. → ее`) and surround a
  non-final surname-first initial with comma pauses (`Рихтер Ч. разработал →
  Рихтер, чэ, разработал`); both settings can be overridden independently.
- Latin `A` is read as `эй`.
- Одиночная латинская буква между русскими словами читается именем буквы
  (`вариант A` → «вариант эй», `уравнение x` → «уравнение икс»). Латинский
  сосед с любой стороны отменяет это чтение: там буква входит в английскую
  фразу или в имя с инициалом.
