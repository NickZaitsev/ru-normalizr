# Выборочная очистка истории — 12 октября 2026

Перед очисткой сохранены полный Git bundle всех доступных ссылок, копия `.git`,
ZIP отслеживаемого дерева и локальные настройки. Bundle проверен через
`git bundle verify`. Пробная очистка выполнена на отдельной зеркальной копии,
после чего тот же фильтр применён к рабочему репозиторию.

Из истории исключены внутренний интеграционный стенд, его тесты и отчёты,
рабочие планы и локальные настройки агента. Сообщения очищены от названий
внутренних сервисов и привязки к продовому пайплайну. Служебные ссылки на
снимки дерева исключены, чтобы они не удерживали прежние материалы.
Разрешённая публичная ссылка в README сохранена, адреса авторов не изменены.

Перед применением фильтра дерево HEAD пробной копии побайтово совпало
с исходным: код, словари, тесты и новые изменения телефонных номеров сохранены.
Ruff и Pyright прошли; полный pytest — 2982 passed, 39 xfailed,
853 subtests passed. Git fsck и Gitleaks на очищенной копии прошли.
Дополнительная проверка всех доступных исторических файлов и сообщений
обнаружила проверенные названия сервисов только в разрешённой ссылке README.

После применения HEAD совпал с проверенной копией, рабочее дерево осталось
чистым, Git fsck прошёл. Настройки origin и отслеживания main восстановлены.
История коммитов сохранена без сквоша, пустые после удаления материалов коммиты
исключены; хэши коммитов и локальные теги изменились. Старые хэши в прежних
инженерных заметках можно сопоставить по commit-map из резервной копии.

На удалённый сервер ничего не отправлялось. До согласованной замены истории
на сервере нельзя выполнять обычный pull/merge со старой историей: он может
вернуть исключённые материалы. Резервная копия содержит исходную историю,
поэтому не предназначена для публикации.
